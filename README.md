## 👨‍💻 About Me

I am a **Computer Engineer** graduated from **Instituto Tecnológico de Costa Rica (TEC)**, working in software engineering, cloud infrastructure, and enterprise data pipelines.

Currently serving as **Lead Developer and CI/CD Owner at P&G (Transportation)**, I lead cloud workload migrations, design enterprise CI/CD standards, build low-latency microservices, and build AI agents that automate developer workflows.

### 🌟 Key Enterprise Achievements

- 💰 **60% Cloud Database Cost Reduction ($144,000/year)**: Analyzed NoSQL database access patterns and migrated workloads from RU-based MongoDB to Azure vCore architecture, cutting monthly operational costs from \$20,000 to \$8,000.
- ⏱️ **~95% Faster CI/CD Deployments**: Slashed build and deployment times from **3 hours to 10 minutes** across ~60% of organizational applications by implementing reusable GitHub Actions workflows.
- ⚡ **99.7% Latency & Payload Optimization**: Optimized payload structures from **~100 MB down to ~300 KB**, accelerating application response times from **3 minutes to ~3 seconds**.
- 🛡️ **AppSec Remediation**: Identified, triaged, and fixed **~300 security vulnerabilities** across mission-critical transportation services.
- 🤖 **AI-Driven Automation**: Built autonomous AI agents to automate technical documentation generation and Agile backlog item creation.
- 📐 **Enterprise System Design**: Produced architecture specifications and defined MVP backlogs for new transportation applications, including the Emergency Action Plan (EAP) core system.
